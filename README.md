# 🏛️ نظام إدارة التأمينات الاجتماعية المتكامل (Egyptian Social Insurance Management System)

> **منظومة رقمية شاملة لإدارة المنشآت والعاملين، إصدار استمارات س١ وس٦ الرسمية بمطابقة تامة، وإدارة العمليات وتحليلات الأجور بدقة واحترافية.**

---

## ✨ المميزات الرئيسية للنظام

1. 📊 **لوحة التحليلات والمؤشرات الاستراتيجية (Executive Analytics Dashboard):**
   - متابعة حية لكتلة الأجور، معدلات الدوران، النمو الوظيفي ونسب الامتثال التأميني.
   - رسوم بيانية تفاعلية لحركة التعيينات والاستقالات وتوزيع المؤهلات والشرائح التأمينية.

2. 🏢 **إدارة الشركات والمنشآت:**
   - تسجيل وأرشفة بيانات الشركات والمؤسسات والمكاتب التأمينية التابعة.
   - استيراد وتصدير سريع للبيانات بصيغ Excel المتوافقة مع أنظمة التأمينات.

3. 👥 **قاعدة بيانات الموظفين:**
   - إدارة ملفات العاملين مع التحقق من صحة الرقم القومي والرقم التأميني.
   - فلاتر متقدمة (مؤمن عليه، غير مؤمن عليه، مستقيل، أرشيف).

4. 📄 **مركز الاستمارات الحكومية الرسمية (Forms Hub):**
   - توليد وطباعة استمارات **س١ (التحاق بالعمل)** و **س٦ (إنهاء الخدمة والتسوية)**.
   - مطابقة 100% لشبكة المربعات الحكومية الأصلية للأوراق الرسمية (A4).
   - وضع ضبط الإحداثيات المباشر (Visual Coordinates Alignment).

5. ⚡ **التحرير الحي المباشر (Live Editor Drawer):**
   - نافذة جانبية ذكية لتعديل وتعبئة البيانات لحظياً مع الربط الفوري بالاستمارة المطبوعة.

6. 🔄 **مركز العمليات والطلبات:**
   - متابعة حركات الاستمارات مع مكاتب التأمينات برقم وتاريخ الوارد والحالة.

7. 📱 **جاهز لتحويله إلى تطبيق موبايل وتحديثه تلقائياً (PWA & Hybrid Ready):**
   - يدعم التثبيت المباشر على الهاتف (Android / iOS) كتطبيق مستقل.
   - خدمة `Service Worker` تضمن التحديث التلقائي الفوري للتطبيق عند أي تعديل يُرفع على GitHub!

---

## 🚀 طريقة التشغيل السريع

### 1. التشغيل المباشر في المتصفح:
- افتح ملف `index.html` في أي متصفح حديث (Chrome / Edge / Firefox / Safari).

### 2. الرفع على GitHub Pages (استضافة سحابية مجانية):
1. ارفع ملفات المجلد على مستودع (Repository) في GitHub.
2. اذهب إلى **Settings > Pages**.
3. اختر فرع **main / root** واضغط **Save**.
4. سيظهر لك رابط الموقع المباشر (HTTPS) فوراً.
